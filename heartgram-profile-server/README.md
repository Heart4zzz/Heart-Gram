# Общие профили HeartGram

Сервис хранит баннеры, параметры рамки, выданные и надетые бейджи, сроки ограничений. База SQLite остаётся на стороне сервера. Профиль и баннер по Telegram ID видны клиентам с адресом этого сервиса. Пользователь подтверждает аккаунт через отдельного бота, прежде чем опубликовать изменения.

## Подключение

1. Создайте отдельного бота у BotFather для подтверждения аккаунтов. Конфигурации с вебхуком потребуется отключить вебхук, поскольку сервис получает события через `getUpdates`.
2. На сервере установите `HEARTGRAM_BOT_USERNAME`, `HEARTGRAM_BOT_TOKEN` и `HEARTGRAM_PROFILE_DB` с постоянным путём к базе. Запустите `python server.py` как отдельный процесс с доступом только к каталогу базы. По умолчанию сервис слушает `127.0.0.1:8315`.
3. Проксируйте HTTP-порт через HTTPS на своём домене. Проверка доступности находится по пути `/health`. Для публичного сервиса настройте ограничение частоты запросов к `/connect` на прокси.
4. Укажите адрес вида `HEARTGRAM_PROFILE_URL=https://profiles.example.com` в `local.properties` и пересоберите APK. Один адрес должен использоваться у всех клиентов.

Токен бота хранится в окружении сервера. В APK нужен только адрес сервиса. Подтверждение привязки действительно пять минут. Сервер разрешает выдавать роли и ограничивать редактирование только с подтверждённого Telegram ID `HEARTGRAM_OWNER_ID`. Developer автоматически доступен этому ID. Banned показывается на время ограничения. Сервис может ограничивать оформление в HeartGram и не изменяет возможности аккаунта в Telegram.

## Ubuntu VPS

Служба [heartgram-profiles.service](deploy/heartgram-profiles.service) запускает приложение отдельным пользователем и сохраняет SQLite в постоянном каталоге `/var/lib/heartgram-profiles`. Перед установкой проверьте, свободен ли локальный порт `8315` и что уже обслуживает HTTPS на ВМ.

Скопируйте `server.py` в `/opt/heartgram-profiles/server.py`, а файл службы в `/etc/systemd/system/heartgram-profiles.service`. При наличии бота сохраните его имя и токен в файле `/etc/heartgram-profiles.env` с доступом только для root. Для запуска выполните `sudo systemctl daemon-reload` и `sudo systemctl enable --now heartgram-profiles`.

Проверьте службу по адресу `http://127.0.0.1:8315/health` и добавьте отдельный маршрут в существующий HTTPS-прокси. В APK указывается публичный адрес этого маршрута. Проверьте `/health` и снаружи ВМ перед сборкой.

Если VPS принимает HTTPS, но у него затруднён исходящий доступ к Telegram Bot API, используйте webhook. Запустите [configure_webhook.py](deploy/configure_webhook.py) в интерактивном терминале на компьютере, откуда доступны Telegram Bot API и SSH на VPS. Скрипт принимает публичный HTTPS-адрес, SSH-пользователя и параметр `--key` с локальным путём к ключу. Токен вводится скрыто, а на VPS сохраняются только имя бота и отдельный секрет для проверки webhook.
